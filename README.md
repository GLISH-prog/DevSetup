# DevSetup

## Présentation

DevSetup est un dépôt regroupant mes livrables réalisés dans le cadre de ma formation à Akieni Academy.

Ce repository contient les différents exercices, projets et travaux pratiques effectués pendant mon apprentissage du développement web.

## Objectifs

Ce projet a pour objectifs de :

- Mettre en pratique les notions apprises durant la formation
- Organiser et suivre l'évolution de mes compétences
- Centraliser mes différents livrables
- Appliquer les bonnes pratiques de développement
